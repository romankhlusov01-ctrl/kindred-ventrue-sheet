# Лист Вентру · Bound by Blood

Два режима:

1. **Создать** — билдер подкласса **Вентру** (Kindred), источники Bound by Blood PDF + dnd.su (Человек, Везучий) + PHB 2024 (Тифлинг).
2. **Играть** — интерактивный лист: проверки / спас / атаки / Kindred → бросок в **журнал** и крупный «последний бросок». Без трекера врагов.

## Играть (стол)

- Вкладки листа: **Проверки · Бой · Kindred · Ещё**
- Dual luck: Везучий (dnd.su) + Защищённый (PDF)
- Нижняя панель: Атака · Питание · Зверь · Ход · ↩
- Sticky HUD: ХП / ОБК / Зверь / Сл

## Создать

Пошаговый билдер → «Применить билд к листу» → **Играть**.
