# Лист Вентру · Bound by Blood

Мобильный **лист только за себя** (без врагов/энкаунтеров).  
D&D 2024 + Kindred / Ventrue · dual luck (Везучий + Защищённый).

## Телефон

- **Нижние вкладки** (большой палец): Игра · Билдер · Навыки · Силы · Черты · Вещи · Ещё  
- **Панель игры** над вкладками: Атака · Питание · Зверь · Ход · ±ХП · ОБК…  
- **Sticky HUD**: ХП · КД · ОБК · Зверь · Сл · Голос · последний бросок  

## Вкладка «Игра»

1. Статус + ход + dual luck  
2. История бросков · быстрые проверки (соц)  
3. Силы сейчас (лечение / голод / Awe / короткий)  
4. Доминирование (Сл, Приказ, Внушение)  
5. Питание · спасброски · эффекты  
6. Атаки  
7. Свёрнуто: силы Kindred, кости, урон/отдых, HD, торпор/кол/солнце
