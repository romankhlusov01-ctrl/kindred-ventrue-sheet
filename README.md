# Лист Вентру · Bound by Blood

**Мобильный лист только за себя** — D&D 2024 + Kindred (клан Ventrue).  
Без трекера врагов: вы, ваши ресурсы, ваши броски.

## С чего начать

1. Вкладка **Билдер** → пресет / шаги → **Применить билд**
2. Вкладка **Игра** (главный экран)
3. Нижняя панель: **Атака · Питание · Зверь · Ход**

## Игра (телефон)

| Зона | Что |
|------|-----|
| Sticky HUD | ХП · КД · ОБК · Зверь + последний бросок |
| Статус | ±ХП, ОБК, Зверь, КД, удача, вдохн./голод |
| Быстрые проверки | Убеждение, Запугивание, Обман… |
| Доминирование | Сл, Приказ/Внушение (−Голос) |
| Питание | Полное / ½ Bane |
| Атаки | Атака+урон одной кнопкой |
| Свёрнуто | Силы, кости, урон/отдых, HD, торпор/кол |

**Нижние вкладки** (большой палец): Игра · Билдер · Навыки · Силы · Черты · Вещи · Ещё  
**Панель игры** над вкладками: основные действия.

## Dual luck

- **Везучий** (dnd.su, человек) — преим. / помеха на атаку по вам  
- **Защищённый** (PDF, Опора) — переброс ≤9 / 0→1  

## Клавиши (десктоп)

`N` ход · `A` атака · `F` питание · `B` зверь · `I` иниц · `H`/`J` ±ХП
