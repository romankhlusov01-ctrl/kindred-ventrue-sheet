# Лист Вентру · Bound by Blood

## Два режима

| Режим | Назначение |
|-------|------------|
| **Создать** | Билдер подкласса **Вентру** (Kindred). Источники: Bound by Blood PDF, dnd.su (Человек, Везучий), PHB 2024 (Тифлинг). |
| **Играть** | Лист за столом: проверки / спас / атаки / Kindred → бросок в журнал. Без врагов. |

После «Применить билд» лист сам переключается в **Играть**.

## Играть

- Вкладки: **Проверки · Бой · Kindred · Ещё**
- Sticky HUD: ХП · ОБК · Зверь · Сл · последний бросок (тап = копировать)
- Dual luck: Везучий + Защищённый
- Низ: Атака · Питание · Зверь · Ход · ↩
- **PDF / печать** — кнопка в шапке (Save as PDF в диалоге браузера)
