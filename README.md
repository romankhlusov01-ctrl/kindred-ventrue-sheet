# Лист Вентру · Bound by Blood

Интерактивный **билдер + соло-ОС** для D&D 2024 + *Vampire: The Masquerade – Bound by Blood* (Kindred / Ventrue).

**Live:** https://kindred-ventrue-sheet.vercel.app  
*(деплой: push в `main` → Vercel; для push нужен write-доступ GitHub)*

## Вкладки

| | |
|---|---|
| **Билдер** | Пресеты, point buy / 4d6, био, навыки, черты, Bane |
| **Бой** | Полный соло-цикл: ход, враги, Сл, спас, питание, отдых |
| **Навыки** | 18 навыков |
| **Способности** | Kindred + Ventrue RAW |
| **Черты** | Toggle + рекомендации |
| **Снаряжение** | Инвентарь, золото, вес |
| **Сессия** | Журнал, сводка, глоссарий |

## Соло-ОС (ключевое)

- Нижняя панель + **Lucky / Protected** + баннер 0 ХП
- **Старт боя:** патруль / охота / сородич
- **Шаблоны врагов** + атака по вам + спас vs ваша Сл
- **Ход всех врагов** · **Иниц всем**
- **Сл Доминирования** + спас NPC
- **Сцена Питания** (Bane ½, привязка к жертве)
- **Спасброски ПК** vs Сл + Protected
- **ASI-хелпер** · кровная связь · пассивы · врем. хиты
- **Цель сцены** · эффекты · порядок инициативы (+союзники)
- Клавиши: `N` ход · `A` атака · `F` питание · `B` зверь · `I` иниц · `H`/`J` ±ХП
- Уязвимость огонь/луч · Daywalker ½ солнца · Awaken

## Dual luck

- **Везучий** (dnd.su) и **Защищённый** (PDF) — два пула = БМ (с учётом мультикласса)
