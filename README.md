# Лист Вентру · Bound by Blood

Мобильный **лист только за себя** (без врагов/энкаунтеров).  
D&D 2024 + Kindred / Ventrue · dual luck (Везучий + Защищённый).

## Телефон · главные идеи

1. **Сценарии** (Бой / Социал / Питание / Отдых) — на экране только нужное  
2. **Нижняя панель** подстраивается под сценарий + **↩ отмена** ХП/ОБК/удач  
3. **Фокус** — прячет шапку; sticky HUD с −/+ по ХП и ОБК  
4. **d20 bar** — N / преим. / помеха + индикатор Зверя  
5. **Атаки play-first** — большая кнопка броска; карандаш = правка  
6. **Питание** — pips крови (тап) · полное / ½ Bane  

## Dual luck

| | |
|--|--|

## Клавиши (десктоп)

`1–4` сценарий · `N` ход · `A` атака · `F` питание · `B` зверь · `Z` отмена · `H`/`J` ±ХП
