# Лист Вентру · Bound by Blood

Мобильный **лист только за себя** (без врагов).  
D&D 2024 + Kindred / Ventrue · dual luck (Везучий + Защищённый).

## Телефон

| Что | Зачем |
|-----|--------|
| **Сценарии** Бой / Социал / Питание / Отдых | На экране только нужное |
| **Нижняя панель** | Меняется под сценарий · ↩ отмена |
| **Фокус** | Прячет шапку |
| **Sticky HUD** | −/+ ХП и ОБК · тап по броску = копировать |
| **d20 bar** | N / преим. / помеха |
| **Питание · pips** | Тап по капле крови |
| **Атаки** | Большая кнопка; карандаш = правка |
| **Быстрые навыки** | «Настроить» — свои 8 |

## Dual luck

| | |
|--|--|
| **Везучий** | преим. d20 / помеха на атаку по вам |
| **Защищённый** | переброс ≤9 / 0→1 хит |

## Клавиши

`1–4` сценарий · `N` ход · `A` атака · `F` питание · `B` зверь · `Z` отмена · `H`/`J` ±ХП
