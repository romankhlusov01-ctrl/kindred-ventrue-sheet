# Лист Вентру · Bound by Blood

Интерактивный **билдер + соло-ОС** для D&D 2024 + *Vampire: The Masquerade – Bound by Blood* (класс Kindred, клан Ventrue).

**Live:** https://kindred-ventrue-sheet.vercel.app

## Вкладки

| Вкладка | Содержимое |
|---------|------------|
| **Билдер** | Пресеты, point buy / массив / 4d6, био, навыки, черты, Bane, механики |
| **Бой** | ХП, кости, ход, враги, Сл, отдых, нижняя панель, hotkeys |
| **Навыки** | 18 навыков + origin setup |
| **Способности** | Поиск по Kindred + Ventrue RAW |
| **Черты** | Kindred feats + рекомендации |
| **Снаряжение** | Инвентарь + золото + вес |
| **Сессия** | Журнал + глоссарий + экспорт |

## Соло-фичи

- Авто-броски (атака+урон, навыки, спас, питание)
- Зверь / Везучий / Защищённый / вдохновение
- Помехи от состояний и Голода
- **Шаблоны врагов:** Страж, Охотник, Волк, Рыцарь, Сородич-враг…
- Враг **атакует вас** (vs ваш КД + урон) · **спас vs ваша Сл**
- Старт боя: патруль / охота / сородич
- Сл Доминирования + бросок спас. NPC
- Цель сцены · временные хиты · быстрые состояния · сцена Питания
- Порядок инициативы (+ союзники)
- Эффекты с таймером раундов
- Awaken / HD / Protected 0→1 / уязвимость огонь-луч
- Нижняя панель: Lucky / Protected / 0 ХП баннер
- Клавиши (desktop): N ход · A атака · F питание · B зверь · I иниц

## Dual luck (RAW)

- **Везучий** (dnd.su, человек): преим. на d20 / помеха на атаку по вам  
- **Защищённый** (PDF, Опора): переброс ≤9 / 0→1 хит  
- Два отдельных пула = БМ
