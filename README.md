# Лист Вентру · Bound by Blood

Мобильный **лист только за себя** — D&D 2024 + Kindred (Ventrue).  
Без трекера врагов: ХП, кровь, удача, атаки, силы, кости.

**Live:** https://kindred-ventrue-sheet.vercel.app

## Вкладки

| | |
|--|--|
| **Игра** | Статус, ход, удача, атаки, питание, доминирование, силы (свёрнуто) |
| **Билдер** | Пресеты, характеристики, черты |
| **Навыки** | Крупные кнопки броска |
| **Силы / Черты** | RAW Kindred |
| **Вещи** | Инвентарь |
| **Ещё** | Журнал, глоссарий, сводка |

## Низ экрана (панель)

Атака · Питание · Зверь · Ход · ±ХП · ОБК · Иниц · Убеждение · (Ещё: удача, отдых, d20)
