# Лист Вентру · Bound by Blood

Интерактивный **билдер + соло-лист** для D&D 2024 + *Vampire: The Masquerade – Bound by Blood* (класс Kindred, клан Ventrue).

**Live:** https://kindred-ventrue-sheet.vercel.app

## Вкладки

| Вкладка | Содержимое |
|---------|------------|
| **Билдер** | Пресеты, point buy / массив / 4d6, био, навыки, черты, Bane, механики, валидация |
| **Бой** | ХП, кости, ход, враги, эффекты, отдых, опасности, карточка, нижняя панель |
| **Навыки** | 18 навыков + origin setup |
| **Способности** | Поиск по Kindred + Ventrue RAW |
| **Черты** | Kindred feats toggle |
| **Снаряжение** | Инвентарь + золото + вес + заметки |
| **Сессия** | Журнал + подсказки |

## Соло-фичи
- Авто-броски (атака+урон, навыки, спас, питание)
- Зверь / Везучий / Защищённый / вдохновение → преимущество
- Помехи от состояний и Голода
- Враги: КД, хиты, vs последний бросок, −урон
- Эффекты с таймером раундов
- Awaken / HD / death saves / Protected 0→1
- Солнце / огонь (уязвимость ×2)
- Копирование карточки для Long Story

## Dual luck (RAW)
- **Везучий** (dnd.su, человек): преим. на d20 / помеха на атаку по вам  
- **Защищённый** (PDF, Опора): переброс ≤9 / 0→1 хит  
- Два отдельных пула = БМ
